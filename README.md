# 伊藤鋳工株式会社｜ホームページリニューアル案

確認用サイト: https://aizumi-droid.github.io/ito-chuko-preview/

現在のサイト案を、写真・製品情報・図面・採用情報を含めて静的サイトとして公開しています。

- GitHub Pages: main ブランチ / ルートディレクトリ
- 各ページは固有の URL から直接表示できます。
- お問い合わせ・採用フォームは画面確認用です。送信機能は接続していません。
- 生成写真には「画像はイメージです」の表示を残しています。
- プレビュー用のため、各ページに noindex を設定しています。
